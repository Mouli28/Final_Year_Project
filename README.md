#  LLM-Based Data Retrieval & Summarization System

##  Overview

This project is an end-to-end AI pipeline that automates data extraction and summarization from large-scale web sources.

##  Problem Statement

Manual data collection and summarization from multiple websites is time-consuming and inefficient.

##  Solution

* Scraped data from 1000+ web pages using Selenium and BeautifulSoup
* Cleaned and structured extracted data
* Used transformer-based LLMs to generate summaries
* Automated the entire pipeline for faster processing

##  Model Details

* Model: Transformer-based LLM
* Task: Text summarization
* Input: Web scraped content

## Results

* Reduced manual effort by 80%
* Improved processing speed by 3x

##  Tech Stack

* Python
* Selenium
* BeautifulSoup
* Transformers
